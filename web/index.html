    Before you make a sound Commissioning checklist
    1. Confirm interface routing, channel wiring, amplifier gain and startup mute with the existing safe commissioning procedure.
    2. Use the correct UMIK calibration file for its serial number and orientation. Keep full-range response measurements, positions and level consistent.
    3. Use a valid acoustic or loopback timing reference for time alignment. Magnitude exports cannot establish delays.
    4. Keep a person present for every audible test. Bound the test duration and provide an immediate mute/revocation path. A chat message or agent assertion is not consent.
    5. Measure before and after. Preserve originals. Avoid boost-heavy correction and never hide unverified hardware behind a smooth curve.
